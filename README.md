# Sanctuary

AI-Powered Church Presentation & Broadcast Platform.

## Requirements
- Windows 11
- Node.js v20+

## Getting Started
1. `npm install`
2. `npm run dev` to start the application in development mode with hot-reloading.

## Building for Production
- `npm run package` to build the Windows NSIS installer (`.exe`).

See `docs/` for architecture and governance guidelines.
